# SQL Project -- College Management Database

## 📌 Project Overview

This project is a **College Management Database** developed using
**MySQL**.\
It contains SQL queries and practice exercises covering database
creation, data insertion, filtering, aggregation, joins, subqueries,
CASE statements, UPDATE/DELETE operations, and window functions.

The main purpose of this project is to practice SQL concepts using a
college-related database and to build strong skills in writing and
understanding real-world SQL queries.

## 🛠️ Technologies Used

-   **MySQL**
-   **SQL**
-   **MySQL Workbench** (for writing and executing queries)

## 🎯 Learning Objectives

Through this project, I practiced:

-   Writing SQL queries from basic to advanced level
-   Retrieving and filtering data
-   Performing calculations using aggregate functions
-   Combining data from multiple tables using JOINs
-   Using subqueries for complex data analysis
-   Working with conditional logic using CASE-WHEN
-   Applying window functions for ranking and row-based analysis
-   Managing database records using INSERT, UPDATE, and DELETE

## ▶️ How to Use

1.  Install **MySQL** and open MySQL Workbench.
2.  Open `Database & table creation.sql`.
3.  Create the database and required tables.
4.  Run the INSERT files to populate the tables with data.
5.  Execute the remaining SQL files to practice and analyze the data.
6.  Run each query individually or as a group in MySQL Workbench.
